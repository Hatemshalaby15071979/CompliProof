Local reconciliation & reporting

Reconcile two exports. Prove what happened.

CompliProof is a local tool that reconciles two CSV exports by their shared key, shows the matched / A-only / B-only rows, and produces HTML, PDF and CSV reports — each backed by a local evidence pack and a hash-chained audit trail. It runs on your machine; it is not a cloud service.

CompliProof 0.1.0 — pre-production candidate, verified locally only. 102 automated tests pass. Hosted GitHub Actions is green on the default branch; local checks pass. Seven P0 release gates remain open (owner-signed closure not recorded).

What it is

CompliProof takes system_a.csv and system_b.csv, reconciles them by id, and reports the union of keys — what matched, what was only in A, and what was only in B. Every report route requires authentication, uploads are temporary and removed after reconciliation, and each result's hash is recorded in a local audit ledger before it is served.

What it does for you

Reconcile

Compare two system exports by key and surface the differences in clear sections.

Report

Generate HTML, PDF and CSV reports from the same reconciliation run.

Evidence pack

A local manifest records approvals and can detect field drift against its own hash.

Audit trail

A local SHA-256 hash chain records each mutation so nothing is invisible.

Honest boundary

This is a pre-production candidate, verified locally only. It is not certified, independently audited, or represented as a compliance determination. Seven P0 release gates remain open (owner-signed closure not recorded), hosted GitHub Actions has not yet run on this candidate, and there is no approved customer deployment or production dataset. A local hash chain is not an external trust anchor — keep the workspace on an encrypted volume, restrict service-account access, and align backups with the 30-day retention policy. See the repository's SHIPMENT_READINESS.md for the exact check outcomes and the remaining gaps.
